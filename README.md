# Dupe Diva (iOS)

Dupe Diva is an iOS fashion discovery application designed to help users explore affordable clothing dupes and visually similar fashion items through a modern, mobile-first shopping experience.

Built using Swift and Xcode, the project explores fashion-tech, recommendation systems, and consumer-focused mobile application development.

---

## Features

- 📸 Fashion-inspired mobile interface
- 👗 Clothing dupe discovery workflow
- 💸 Affordable style exploration
- 📱 Native iOS application
- ⚡ Smooth scrolling and interactive UI components
- 🎨 Modern fashion-focused user experience

---

## Tech Stack

- Swift
- Xcode
- CocoaPods
- UIKit
- iOS SDK

## Getting Started

### Prerequisites

- Xcode
- CocoaPods
- iOS Simulator or physical iPhone device

### Installation

Clone the repository:

```bash
git clone https://github.com/rhea-modey/dupediva.git
```

Install CocoaPods dependencies:

```bash
pod install
```

Open the workspace file:

```bash
open dupediva.xcworkspace
```

Run the project using Xcode and an iOS simulator or physical device.
